# Incremental publication

Profiles are no longer embedded in the shared JavaScript. `editor.html` remains a complete, readable page without JavaScript. SPA navigation fetches `editor-profile.json` with cache revalidation. Both are generated by `scripts/profile_build.py` from the native biography renderer and author data.

`scripts/build_pipeline.py` fingerprints tracked production inputs and verifies every reused output file against its SHA-256 inventory before selecting work:

| Changed input | Generation |
| --- | --- |
| `editor_profile.json`, `profile_content.py`, profile builder | Author page and independent payload only |
| `src/app/` | Shared client bundle only |
| CSS/JavaScript in `src/assets/` | Changed delivery assets only |
| Song/catalog data, source images, templates, shared generators | Complete related site build, using the existing content-addressed image encoding cache |
| Explicit documentation files | No generation or publication |
| Missing/corrupt output cache | Full bootstrap build |

Unknown production inputs conservatively select a full build. Input deletion is included in the fingerprints. Changes after planning are rejected. The output cache is saved only after validation succeeds. Complete Pages artifacts still contain unchanged files; copying/uploading these is required by Pages and does not regenerate songs or decode/re-encode images.

The workflow validates the current authored biography, links, SEO, images, JavaScript syntax and direct/SPA navigation. It no longer uses old fixed paragraph/song counts or byte-identical historical workflow snapshots as gates for unrelated content updates. Those historical verifiers remain in the repository for reference. Deployment stays restricted to the current `main` SHA, excludes pull requests and keeps the patched Node runtime and existing deployment permissions.

Tests: `python -m unittest discover -s scripts -p test_build_pipeline.py`; `python scripts/validate_site.py`; `node scripts/verify_profile_independent.cjs` against the local preview server.
