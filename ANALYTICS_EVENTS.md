# Additive GA4 events

Existing playback, playlist, sharing and creator-site events remain unchanged. Added: select_filter (fixed filter_key only), select_listening_shelf (public shelf_id), art_open (manual display succeeded), sample_playback_start (YouTube sample iframe reports playing; repeated state ignored). The iframe source window and YouTube origin are checked. Search terms and playlist names are excluded. GA4 property key-event settings and receipt confirmation remain separate.
