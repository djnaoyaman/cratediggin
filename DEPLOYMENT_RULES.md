# Independent corrective releases

User instruction, 2026-10-20 JST: deploy one independent fix, verify production, then proceed to the next. Group changes only when they genuinely depend on one another. Do not hold a ready correction for unrelated artwork, content, or unfinished improvements.

Each release retains its focused regression tests, exact content/asset preservation, required CI and production verification. Freeze its scope when CI starts; subsequent independent requests belong to the next release. Report completed publications separately. This is an internal production rule, not public editorial copy.
